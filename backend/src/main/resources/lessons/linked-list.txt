WHAT IT IS
A linked list is a chain of nodes. Each node holds a value and a pointer (next) to the following node. Unlike an array, nodes can sit anywhere in memory, so inserting or deleting a node only changes pointers and needs no shifting.

REAL-LIFE ANALOGY
A treasure hunt: each clue tells you where the next clue is. You cannot jump to clue 5 directly, you must follow the chain from the start.

KEY TERMS
- Node: one box with a value and a next pointer
- Head: the first node, the only way into the list
- Tail: the last node, its next is null
- Dummy node: a fake node placed before the head to simplify edge cases
- Fast and slow pointers: two pointers moving at different speeds

WHEN TO USE IT
- Reverse a list, or part of it
- Detect a cycle, or find where a cycle starts
- Find the middle node, or the n-th node from the end
- Merge two sorted lists
- Remove or insert nodes without extra memory

CODE: REVERSE A LINKED LIST
ListNode prev = null;
ListNode cur = head;
while (cur != null) {
    ListNode next = cur.next;
    cur.next = prev;
    prev = cur;
    cur = next;
}
return prev;

CODE: DETECT A CYCLE (FAST AND SLOW)
ListNode slow = head, fast = head;
while (fast != null && fast.next != null) {
    slow = slow.next;
    fast = fast.next.next;
    if (slow == fast) {
        return true;
    }
}
return false;

WORKED EXAMPLE
Reverse 1 -> 2 -> 3 -> null. Three variables: prev, cur, next.
  start         prev=null  cur=1
  save next=2   flip 1.next to null    prev=1  cur=2
  save next=3   flip 2.next to 1       prev=2  cur=3
  save next=null  flip 3.next to 2     prev=3  cur=null
Loop ends, prev points to 3. New list: 3 -> 2 -> 1 -> null.
Always do the three moves in this order: save next, flip pointer, move forward.

PATTERNS YOU WILL MEET
- Reverse: Reverse Linked List, Reverse Nodes in k-Group
- Fast and slow: Linked List Cycle, Middle of the Linked List
- Dummy node: Remove Nth Node From End, Merge Two Sorted Lists
- Gap of n: move one pointer n steps ahead, then move both together
- Combine tricks: Reorder List (find middle, reverse second half, merge)

COMPLEXITY
Reaching the k-th node is O(k), there is no direct index. Insert or delete after you hold the node is O(1). Most list problems are O(n) time and O(1) extra space.

COMMON MISTAKES
- Losing the rest of the list by changing next before saving it
- Not handling an empty list or a single node
- Using fast.next.next without checking fast and fast.next for null
- Forgetting to return the new head after reversing or removing the first node

INTERVIEW TIPS
- Draw boxes and arrows on paper and move your finger as the pointers move
- Reach for a dummy node whenever the head itself might be removed
- Say "I will do it in one pass with O(1) space" and then do it

PRACTICE ROADMAP
1. Easy: Reverse Linked List, Merge Two Sorted Lists, Linked List Cycle
2. Medium: Remove Nth Node From End, Reorder List, Add Two Numbers
3. Hard: Reverse Nodes in k-Group, Merge k Sorted Lists

QUICK RECAP
- Save next, flip the pointer, move forward
- Fast and slow pointers find cycles and middles
- A dummy node removes most edge-case headaches
