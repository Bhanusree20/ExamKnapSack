WHAT IT IS
Two pointers means using two index variables that move through the data instead of using nested loops. A sliding window is a special case where the two pointers mark the start and end of a window that grows and shrinks. Both turn O(n^2) work into O(n).

REAL-LIFE ANALOGY
Two pointers: two people searching a sorted bookshelf, one from each end, meeting in the middle. Sliding window: a magnifying glass moving along a line of text, widening when you need more and narrowing when you have too much.

KEY TERMS
- Left and right pointers: the two indexes, often starting at both ends
- Window: the part of the array between left and right
- Fixed window: the window size never changes
- Variable window: grow right, shrink left while a rule is broken
- Invariant: the rule that is always true about the window (for example "no repeated letters")

WHEN TO USE IT
- The array is sorted and you need a pair or triplet with a target sum
- You need to reverse or check a palindrome in place
- "Longest or shortest substring or subarray that satisfies a rule"
- "Maximum sum of any k consecutive items"
- You want to remove duplicates or move items in place with O(1) extra space

CODE: TWO POINTERS ON A SORTED ARRAY
int left = 0, right = nums.length - 1;
while (left < right) {
    int sum = nums[left] + nums[right];
    if (sum == target) {
        return new int[] { left, right };
    }
    if (sum < target) {
        left++;
    } else {
        right--;
    }
}
return new int[] {};

CODE: VARIABLE SLIDING WINDOW (LONGEST SUBSTRING WITHOUT REPEATS)
Set<Character> window = new HashSet<>();
int left = 0, best = 0;
for (int right = 0; right < s.length(); right++) {
    while (window.contains(s.charAt(right))) {
        window.remove(s.charAt(left));
        left++;
    }
    window.add(s.charAt(right));
    best = Math.max(best, right - left + 1);
}
return best;

WORKED EXAMPLE
Sorted array [1, 3, 4, 6, 8, 11], target 10.
  left=0 right=5  1+11=12  too big, move right left
  left=0 right=4  1+8=9    too small, move left right
  left=1 right=4  3+8=11   too big, move right left
  left=1 right=3  3+6=9    too small, move left right
  left=2 right=3  4+6=10   FOUND
Each step throws away one number for sure, so it ends in at most n steps.

PATTERNS YOU WILL MEET
- Opposite ends: Two Sum II, 3Sum, Container With Most Water, Valid Palindrome
- Fast and slow: remove duplicates, move zeroes
- Fixed window: maximum average of k items
- Variable window: Longest Substring Without Repeating Characters, Minimum Window Substring

COMPLEXITY
Each pointer moves in one direction only, so the total work is O(n). Extra space is O(1) for plain pointers, or O(k) if you keep a set or map of the window.

COMMON MISTAKES
- Using two pointers on an array that is not sorted (the "which pointer to move" logic needs order)
- Off-by-one: the window length is right - left + 1
- Forgetting to shrink the window inside a while loop (an if only removes one item)
- In 3Sum, not skipping duplicate values, which gives repeated triplets

INTERVIEW TIPS
- Say the invariant in words: "my window never contains a repeated character"
- For 3Sum, sort first, fix one number, then two pointers on the rest
- Draw the array and write L and R under it, it makes the move rule obvious

PRACTICE ROADMAP
1. Easy: Valid Palindrome, Two Sum II, Move Zeroes
2. Medium: 3Sum, Container With Most Water, Longest Substring Without Repeating Characters
3. Hard: Minimum Window Substring, Trapping Rain Water

QUICK RECAP
- Two pointers need order (sorted data), a window needs a rule
- Move the pointer that fixes the problem
- Each element is visited a constant number of times, so O(n)
